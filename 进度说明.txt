# 给 AI 的改进任务说明版

```text
我在做一个 Python 音乐视频处理项目，当前目标是：

1. 输入原视频和外部音乐
2. 从原视频中提取音频
3. 对外部音乐进行降噪
4. 将外部音乐与原视频音频对齐
5. 将“对齐后的音频”与“原视频音频”混合
6. 输出一个新视频，画面不变，音频为混合后的结果

当前状态：
- `align_audio()` 已经能正确对齐原视频音轨
- 现在不是要替换原视频音频，而是要把对齐后的音频和原视频音频混合
- 最终输出 mp4 视频

技术栈：
- Python
- ffmpeg-python
- librosa
- soundfile
- numpy
- noisereduce（可选）

当前项目结构：
- `audio_processor.py`
- `video_processor.py`
- `main.py`

已实现的功能：
- `analyze_video(video_path)`：分析视频信息
- `extract_audio_from_video(video_path, output_audio_path)`：提取视频音轨
- `denoise_audio(audio_path, output_audio_path)`：对音乐降噪
- `align_audio(query_audio_path, reference_audio_path, output_audio_path)`：将音乐对齐到视频音轨
- `mix_audio_with_video(video_path, aligned_audio_path, output_video_path, ...)`：将原视频音频和对齐后的音频混合后输出视频
- `enhance_video()`：兼容入口，内部实际调用混音函数

当前需求：
- 继续优化这个项目
- 保持已有流程不变
- 优先提升“音频对齐准确率”、“混音效果”、“输出稳定性”

我希望你重点帮我做这些事：
1. 检查现有代码是否有逻辑错误或潜在 bug
2. 优化音频对齐算法，让对齐更准确
3. 优化混音逻辑，避免爆音、失真、音量不平衡
4. 提高 ffmpeg 输出 mp4 的稳定性
5. 如果需要，可以重构代码结构，但要尽量保持接口兼容
6. 给出可以直接复制运行的完整修改版代码，而不是只给思路

我希望你的回答格式：
- 先说明你准备怎么改
- 然后直接给出修改后的代码
- 如果有关键参数，请顺便告诉我默认值怎么调
- 如果发现我现有代码有问题，请明确指出问题所在和修复方案

如果需要我提供当前代码，请告诉我我应该贴哪几个文件：
- `audio_processor.py`
- `video_processor.py`
- `main.py`
- 或者具体报错信息
```

# 更短一点的版本

如果你想更快地发给 AI，也可以用这个短版：

```text
我有一个 Python 项目，用于视频音轨处理。流程是：提取视频音频 -> 外部音乐降噪 -> 音频对齐 -> 将对齐后的音频与原视频音频混合 -> 输出 mp4。

当前 `align_audio()` 已经能正确对齐。现在我的需求不是替换原视频音频，而是混合原视频音频和对齐后的音频。

请你基于我现有的 `audio_processor.py / video_processor.py / main.py` 继续优化：
1. 提高对齐准确率
2. 优化混音，避免爆音和音量不平衡
3. 提高 ffmpeg 输出稳定性
4. 尽量保持现有函数接口兼容
5. 直接给我可运行的完整代码修改版

如果你需要，我可以贴出当前代码或报错信息。
```

# 你以后发给 AI 时，最好再补充这三样

为了让 AI 更容易继续改进，你可以在说明后面追加：

1. **当前代码**
   - `audio_processor.py`
   - `video_processor.py`
   - `main.py`

2. **当前报错**
   - 完整 traceback
   - 或者 ffmpeg 的控制台输出

3. **你想要的最终效果**
   - 是“混音”
   - 还是“替换音轨”
   - 或者“保留原音但降低音量后叠加”
